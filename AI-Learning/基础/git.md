### How we should be using Git
#### 地址
https://drewdeponte.com/blog/how-we-should-be-using-git/?continueFlag=4eb33b14b5288121f74719c13c0c4a02
#### 简介
一篇介绍如何正确使用Git的文章。“正确”是参考了Linux内核团队的工作流程。  
文章强调了Git的设计理念和长期软件开发维护的最佳实践，包括如何将代码变更分解为小的、逻辑独立的、可构建和可测试的补丁，并通过电子邮件或现代工具如GitHub进行提交和审查。  
文章还介绍了“从外到内”（Outside-In）的开发方法和“补丁栈”（Patch Stack）的概念，帮助开发者更有效地管理和维护代码。
